## Before you start

- [ ] Build once so the live runs don't compile on stage: `swift build -c release`
- [ ] Terminal open in the repo folder, with the font large enough to read from the back
- [ ] Editor open with the files your section walks through
- [ ] Laptop plugged in, Low Power Mode off, heavy apps closed (affects the priority run)
